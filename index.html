mail-bot

A private Telegram bot. Last updated: 2026-10-07.

mail-bot relays the newest e-mail from a few pre-configured senders in its owner's Gmail inbox to a small whitelist of Telegram users. From each matching message it extracts only a configured fragment (for example a one-time sign-in code) and sends that fragment, together with the time the message was received, to the user who pressed the button.

It is operated by a single individual for personal use and is not offered to the public.

Privacy policy

Google user data accessed

The bot uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly, granted by the owner of the mailbox. It searches the inbox for messages from the configured senders and reads those messages to extract the configured fragment. It cannot send, modify, label or delete mail.

How the data is used

  • Message content is processed in memory only, at the moment a whitelisted user requests it.
  • Only the extracted fragment and the received-at time are delivered, via Telegram, to that whitelisted user.
  • E-mail content is not stored: no message bodies, subjects or addresses are written to disk or to the database.
  • Data is not sold, not used for advertising, not used to train AI or ML models, and not shared with anyone other than the requesting whitelisted user.

Data stored

To manage the whitelist the bot stores, for each Telegram user it admits: Telegram user id, username and display name, who invited them and when; and single-use invite codes with their expiry. This data is deleted when the administrator removes the user from the whitelist. The OAuth refresh token is kept only in the server's configuration.

Limited Use

mail-bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The mailbox owner can revoke the bot's access to Gmail at any time at myaccount.google.com/permissions. Telegram users can ask the administrator to remove them from the whitelist.
